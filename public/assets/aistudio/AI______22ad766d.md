# 安卓文件浏览器 · AI 提示要求（v1.1 晴彩配色）

> 本文件是**可直接复制粘贴给 AI 的提示词包**，配合另外三份文件使用：
> - `文件浏览器-UI与交互设计方案.md` —— 完整设计规格（页面结构、交互、token、暗色模式、动效）
> - `素材/视觉素材板.svg` —— 矢量素材板，**整张作为风格参考图上传**（图生图 / 风格迁移）
> - `素材/配色与素材预览.html` —— 可运行预览，可截图作参考、可复制全套 CSS token
>
> **三条铁律**：① 色值只能从 §2 变量表取，禁止 AI 自行改 hex；② 每条提示词后面必须附上 §3 约束块；③ 每次都带 §4 负面词。

## 3 · 一致性约束 CONSTRAINT_BLOCK（**每条提示词后必须原样附上**）

```
必须遵守以下六条约束：
1) 彩色只进容器、不进文字：文件名、元数据、正文、设置标签一律中性色；彩色只出现在图标方格、分类格、进度分段、插画、选中态、主按钮。
2) 主色仍唯一：{{PRIMARY}} 是唯一主操作色；8 组类型色只做类型识别，绝不用于按钮、选中态、导航或主操作。
3) 饱和度锁带：所有类型色锁定 S 65~78% / L 58~68%，不出现荧光色与深色并存；暗色统一降饱和 + 提亮。
4) 一屏彩色不超过 5 组；分类宫格 8 格为例外，但必须用统一方格形状与统一浅底明度收敛，不加描边和阴影。
5) 骨架不变：行 + 1px 缩进分隔线、每屏卡片 ≤3 张、顶部图标 ≤4 个、圆角单源派生、阴影只给浮层。
6) 渐变克制：仅 FAB / 进度条 / 成功确认等小面积强调位用 {{PRIMARY}} → {{PRIMARY_2}} 双色 135° 渐变；禁止大面积渐变背景、禁止三色及以上渐变、禁止类型色渐变。
另外：所有可点区域 ≥44×44dp；状态齐全（空态、加载、错误、选中、无权限）；暗色模式下边框用透明白 10%、类型色降饱和提亮；中文文案真实具体，不用占位符；不使用 iOS 刘海 / Home 指示条 / 侧边抽屉。
```
