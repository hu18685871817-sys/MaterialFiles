# 基于 Material Files（质感文件）对标 ES & RS 文件浏览器的详细 UI 与功能实现规范

> **文档定位**：本文档结合 [Material Files（质感文件）](https://github.com/zhanghai/MaterialFiles/blob/master/README.md) 的开源底座，对照 [ES 文件浏览器](https://en.wikipedia.org/wiki/ES_File_Explorer)（[APKMirror](https://www.apkmirror.com/apk/es-global/es-file-explorer/es-file-explorer-file-manager-4-4-3-5-release/)）与 [RS 文件管理器](https://www.apkmirror.com/apk/rs-mobile-group/rs-file/rs-file-manager-file-explorer-2-3-0-release/)（[SourceForge](https://sourceforge.net/software/product/RS-File-Manager/)）的**每一个具体功能与对应 UI 界面**进行逐控件、逐弹窗的精细化描述，可直接提交给 Google AI（如 Google AI Studio）用于生成 Android XML / Jetpack Compose 界面与业务逻辑代码。

---

## 1. 设计系统与全局框架 UI（Global Shell）

### 1.1 视觉基调（继承 Material Files + 对齐 ES/RS 信息密度）
- **色彩与主题**：保留 Material Files 的动态主题色（Primary/Accent）与夜间模式（含纯黑 `#000000` AMOLED 背景）。卡片统一使用 `16dp` 圆角，弹窗与底部面板（BottomSheet）使用 `24dp` 顶部圆角。
- **字体层级**：页面大标题 `20sp` Medium；列表主标题 `15sp` Regular；副标题/路径/时间 `12sp` Secondary；等宽数据（IP、端口、字节数、MD5）使用 `monospace`。

### 1.2 顶部双层导航栏（Top App Bar + Multi-Tab Strip）
整个应用主框架采用 `CoordinatorLayout` + `AppBarLayout` 固定顶部双层结构：
- **第一层（主工具栏，高度 `56dp`）**：
  - **最左侧**：汉堡菜单图标（`24dp`），点击滑出快速访问侧边栏；当处于子目录或非主页时可切换为返回箭头或保留菜单图标。
  - **中间区域**：当前激活窗口的标题（如「主页」或当前文件夹名）或全局搜索框。
  - **右侧动作区**（从左到右依次排列）：
    1. **搜索图标**：点击后工具栏平滑展开为圆角搜索输入条（含「按名称 / 类型 / 大小 / 日期」筛选胶囊按钮）。
    2. **视图与排序图标**：点击弹出 `PopupMenu` 或紧凑 `BottomSheet`，上半区切换「列表 / 网格（2列/3列/4列）/ 详细信息」，下半区选择排序字段（名称、大小、修改时间、类型）及升降序。
    3. **更多菜单（三点图标）**：包含「新建」「全选」「添加到书签」「创建桌面快捷方式」「设置」。
- **第二层（多标签页切换条，高度 `40dp`）**：
  - 采用横向 `RecyclerView` / `TabLayout`，每个标签页为胶囊或圆角矩形样式（激活态高亮背景 + 底部 `2dp` 指示条）。
  - 固定首项为「主页（图标+文字）」，右侧依次为打开的目录标签（如 `内部存储`、`Download`、`SMB-NAS`），每个非主页标签右侧带 `×` 关闭按钮，末尾固定 `+` 按钮用于新建空白或默认目录标签。
  - **手势**：主内容区绑定 `ViewPager2`，支持**左右滑屏**在已打开的标签页之间无缝切换。

### 1.3 快速访问侧边栏抽屉（Fast Access Navigation Drawer）
宽度 `300dp`，从屏幕左侧滑出，顶部为 `110dp` 品牌/存储概览头图（显示应用名与当前总可用空间），下方为分组可滚动菜单：
- **分组 1（收藏夹）**：可折叠分组，列出用户添加书签的目录（文件夹图标 + 目录名 + 右侧移除按钮）。
- **分组 2（本地存储）**：内部存储（带小容量条）、外置 SD 卡（检测到时显示）、USB OTG（带右侧「安全弹出」图标）、根目录 `/`（开启 Root 后显示）。
- **分组 3（网络与云盘）**：局域网（LAN/SMB）、FTP/SFTP/WebDAV、云盘网盘、远程管理（PC 访问）、ES Share 快传。
- **分组 4（工具开关区，带右侧 `Switch` 开关）**：
  - `Root 浏览器`（开启时若无权限则请求 `su` 授权）。
  - `显示隐藏文件`（控制是否展示 `.` 开头文件/文件夹）。
  - `回收站`（控制删除操作是否拦截进入回收站）。
- **分组 5（底部固定栏）**：左半部分「下载管理器」，右半部分「设置」。

### 1.4 底部上下文操作栏与「范围选择」（Multi-Select & Range Selection）
- **常规态**：无底部栏，右下角悬浮 `56dp` 圆形主按钮（FAB，`+` 号图标）。点击 FAB 向上展开 3 个带文字标签的小圆按钮：`新建文件夹`、`新建文本文件`、`粘贴（剪贴板有内容时显示）`。
- **多选态**：长按任意文件或点击左侧图标区触发：
  - **顶部栏变化**：原工具栏替换为深色/强调色上下文栏（Contextual Action Bar），左侧为 `×` 退出按钮 + `已选 N 项` 计数；右侧依次为：**「范围选择」图标（双向区间箭头）**、**「全选/反选」图标**。
  - **范围选择交互**：当用户至少勾选了 2 个不连续的文件（例如第 2 项和第 15 项）时，「范围选择」图标从半透明变为完全高亮；点击后自动勾选索引 2 到 15 之间的全部条目，并震动反馈。
  - **底部操作栏（高度 `64dp`，均分 5 列图标+文字）**：`复制`、`剪切`、`删除`、`重命名`、`更多`（点击弹出上拉菜单：`压缩`、`加密锁定`、`隐藏`、`分享`、`添加书签`、`属性`）。
- **剪贴板粘贴悬浮条**：点击复制或剪切后退出多选，屏幕底部出现 `48dp` 高的悬浮条（左侧显示 `已复制 N 项`，右侧两个按钮：`取消`、`粘贴至此`）。

## 2. 核心页面与功能级 UI 详细设计

### 2.1 主页看板（Home / Dashboard）
采用单列纵向滚动布局，内边距 `16dp`，卡片间距 `12dp`：
1. **设备概览统计条（RS 特色）**：
   - 紧贴 Tab 栏下方，通栏圆角矩形条（高度 `44dp`），左右均分显示：`文件总数：14,820` | `已安装应用：86`。
2. **存储空间卡片轮播（HorizontalPager）**：
   - 卡片宽度占屏幕 `88%`（右侧露出下一张卡片边缘暗示可滑动），高度 `116dp`。
   - **卡片内部布局**：左上角存储图标 + 名称（如「内部存储」）；右上角「空间分析 >」文字按钮；中部为 `8dp` 高圆角横向进度条；底部左侧显示 `已用 84.2 GB / 128 GB`，底部右侧显示 `剩余 43.8 GB (34%)`。
   - **异常态**：未授予所有文件权限时，此处变为警示色横幅卡片，显示「需要授予文件访问权限以管理完整存储」+ 右侧「去授权」按钮。
3. **媒体分类宫格（3 列 × 3 行或 4 列 × 2 行）**：
   - 每个宫格单元高度 `84dp`，居中放置 `32dp` 彩色分类图标、下方 `13sp` 分类名（图片、视频、音频、文档、压缩包、安装包 APK、下载、应用管理）、最下方 `11sp` 灰色实时计数（如 `1,248 项`）。
4. **最近文件横向流（Recent Files）**：
   - 标题行：左侧「最近文件」，右侧「全部 >」。
   - 内容区：横向滚动卡片（宽 `96dp` × 高 `116dp`），上方 `72dp` 为圆角缩略图（图片/视频首帧/文件类型色块），下方 2 行小字显示文件名与相对时间（如 `10分钟前`）。
5. **收藏夹与快捷工具区**：
   - 上半区：横向滚动胶囊标签（`Chip`），展示用户收藏的文件夹快捷入口。
   - 下半区：4 列图标入口（空间分析、远程管理、回收站、128 位加密保险箱）。

### 2.2 本地存储与文件操作弹窗 UI（Local Storage & Dialogs）
- **文件列表行布局（高度 `64dp`）**：
  - 左侧（`40dp×40dp`）：圆角 `8dp` 缩略图或文件夹/格式图标；若为符号链接，右下角叠加小箭头角标；若为加密文件，右下角叠加小锁角标。
  - 中间主区：第一行 `15sp` 文件名（单行省略或两行）；第二行 `12sp` 灰色副标题（左侧显示修改时间 `2026-11-16 14:20`，中间分隔符 `·`，右侧显示文件大小或文件夹子项数 `24 项`，Root 模式下末尾追加 Linux 权限 `rwxr-xr-x`）。
  - 右侧：可拖拽快速滚动条（Fast Scroller，拖动时左侧悬浮 `48dp` 圆形气泡显示当前首字母或日期）。
- **复制 / 移动进度弹窗（ES 规范 AlertDialog）**：
  - 顶部标题：`正在复制 (12 / 45)`。
  - 路径区：两行小字分别显示 `从：/storage/emulated/0/Download` 与 `到：/storage/1234-5678/Backup`。
  - 当前文件区：显示正在传输的单个文件名 + 单文件线性进度条。
  - 总体进度区：总进度条 + 下方三栏实时数据（左侧 `45.2%`，中间 `速率 38.4 MB/s`，右侧 `剩余 00:18`）。
  - 底部按钮：`后台运行`（最小化为系统通知栏进度条）、`取消`。
- **同名文件冲突弹窗**：
  - 标题：`目标位置已存在同名文件`。
  - 中部对比区：左右两列卡片对比「源文件」与「目标文件」的缩略图、大小与修改时间。
  - 复选框：`[ ] 对所有剩余冲突文件执行此操作`。
  - 底部三按钮：`跳过`、`重命名（自动加序号）`、`覆盖`。
- **详细属性弹窗（ES 精确校验规范）**：
  - 顶部：文件大图标 + 可编辑/可复制的文件名。
  - 信息表（左键右值）：`类型`、`位置`（点击可复制路径）、`大小`（**同时显示可读值与精确字节数**，如 `1.24 GB (1,331,439,861 字节)`）、`包含`（文件夹专属，实时异步统计 `X 个文件，Y 个文件夹`）、`修改时间`、`权限与所有者`（点击「更改」弹出 `rwx` 9 宫格勾选框）、`校验值`（点击「计算」异步生成 MD5 与 SHA-256）。

### 2.3 媒体分类浏览页（Library / Categories）
- 顶部保留分类切换 Tab（图片 | 视频 | 音频 | 文档 | APK | 压缩包），支持左右滑动切换分类。
- **图片/视频视图**：默认切换为 **3 列紧凑网格**（间距 `2dp`），右上角显示视频时长胶囊标签（如 `04:32`）；支持按「拍摄日期 / 文件夹」分组吸顶标题。
- **音乐视图**：列表项显示专辑封面、歌名、歌手、时长与格式（FLAC/MP3），点击直接呼出底部迷你播放器。
- **APK 安装包视图**：自动解析未安装 `.apk` 的包名、版本号，并在右侧显示状态徽标（`未安装` / `已安装 v1.0` / `可升级`）。

### 2.4 网络、局域网与云盘页（Network, LAN & Cloud）
1. **网络主列表页**：
   - 分组展示：`局域网共享 (SMB/NAS)`、`FTP / SFTP / WebDAV`、`云盘网盘`。
   - 顶部右侧「+ 添加」按钮弹出协议选择网格（SMB 2.0、FTP、FTPS、SFTP、WebDAV、Google Drive、Dropbox、OneDrive、Box、Yandex、MEGA、NextCloud）。
   - 点击「扫描局域网」时，顶部出现雷达扫描动画条，实时将发现的电脑/NAS IP 以卡片形式插入列表。
2. **服务器配置弹窗（SMB / FTP / WebDAV）**：
   - 表单字段：显示名称（选填）、服务器地址/IP、端口（按协议自动预填如 SMB `445` / FTP `21` / SFTP `22`）、用户名、密码（带小眼睛明文切换）、匿名登录开关、编码选择（UTF-8 / GBK）、验证模式/密钥导入（SFTP）。
3. **远程管理页（Remote Manager / PC 访问）**：
   - **顶部**：返回键 + 标题「远程管理」+ 分段控制器（`FTP 服务` / `HTTP 网页端`）+ 右上角设置齿轮。
   - **状态核心卡片（高度 `180dp`）**：
     - 未启动态：居中 Wi-Fi 图标 + 当前网络名称（如 `已连接 Wi-Fi: Home_5G`）+ 提示语「点击下方按钮开启局域网传输」。
     - 运行态：绿色状态点 `服务运行中` + 大号等宽地址 `ftp://192.168.1.108:3721` + 并排两个功能按钮（`复制地址`、`显示二维码`）+ 底部小字 `当前已连接客户端：1 台`。
   - **配置项列表**：共享根目录（点击呼出目录选择器）、端口号（默认 3721/8080）、访问验证（匿名 / 随机密码 / 自定义账号密码）、编码格式（UTF-8 / GBK）、传输时保持屏幕常亮开关。
   - **底部主按钮**：通栏 `48dp` 圆角按钮（`启动服务` / `停止服务`），启动后同步推送常驻前台通知。
4. **设备间快传（ES Share）**：
   - 顶部左右切换「发送」与「接收」；中间显示雷达动画及附近同局域网设备头像；底部展示传输队列进度与速率。

### 2.5 工具箱与系统管理页面（Tools & Utilities）
1. **空间分析页（Disk Analysis）**：
   - **顶部**：返回键 + 存储介质下拉框（内部存储 / SD 卡）+ 重新扫描按钮。
   - **可视化总览卡片**：左侧 `96dp` 环形占比图（中心显示已用百分比 `66%`），右侧 2 列 3 行图例（视频、图片、音频、文档、安装包、其他，各自带颜色圆点与 GB 数值）。
   - **维度 Tab 栏**：`文件夹排行` | `大文件 (>100MB)` | `冗余与空文件` | `最近新增`。
   - **列表项设计**：文件夹行右侧显示精确体积与占当前父目录的横向占比条；点击文件夹支持**无限下钻**并出现面包屑路径；长按多选后底部弹出「移入回收站」「彻底删除」「打开所在目录」。
2. **应用管理器页（App Manager）**：
   - **顶部**：返回键 + 标题（含总数）+ 搜索 + 排序（名称/大小/安装时间/更新时间）+ 设置备份路径按钮。
   - **三段 Tab**：`用户应用` | `系统应用` | `已备份 APK`。
   - **列表项**：`44dp` 应用图标 + 主标题（应用名 + 版本号）+ 副标题（包名 + 安装日期）+ 右侧体积；若为 Split APKs 则带 `Split` 小标签。
   - **点击弹出操作 BottomSheet**：顶部展示应用头部信息，下方为网格或列表动作：`打开应用`、`备份 APK`、`卸载`、`分享`、`作为 ZIP 浏览内部资源`、`查看详情（包名/签名/权限/TargetSDK）`、`创建桌面快捷方式`。
3. **回收站页（Recycle Bin）**：
   - **顶部**：返回键 + 标题「回收站」+ 开关/保留天数设置（7天/15天/30天）+ 排序 + 「清空」按钮。
   - **提示横幅**：浅色条显示 `共 N 项 · 占用 X GB · 到期自动清理`。
   - **列表项**：缩略图 + 文件名与大小 + 灰字`原路径: /Download/...` + `删除时间 · 剩余 X 天`（不足 3 天标红）+ 右侧快捷「还原」图标。
   - **还原冲突**：若原目录已被删则自动重建；若原路径存在同名文件则弹出标准同名冲突弹窗。
4. **128 位文件加密保险箱（Encryption Vault）**：
   - **解锁页**：居中锁图标 + 密码输入框 / 6 位数字键盘 + 指纹/面容生物识别快捷按钮。
   - **保险箱列表**：仅展示已加密文件（扩展名或内部标记为加密容器），支持在安全视图内直接预览或「解密还原至原目录/指定目录」。
5. **下载管理器（Download Manager）**：
   - 顶部两栏 Tab：`下载中` | `已完成`。
   - 列表项显示文件名、下载 URL 域名、进度条、实时速度、暂停/继续按钮；右上角 `+` 支持手动粘贴 HTTP/HTTPS 直链新建下载任务。

### 2.6 内置查看器与播放器（Built-in Viewers & Players）
1. **压缩包浏览器（Archive Viewer — 对齐 RS 文件夹式直览）**：
   - 点开 `.zip` / `.rar` / `.7z` / `.tar` / `.obb` 或在应用管理中点「作为 ZIP 浏览 APK」时，**不弹出简陋弹窗，而是直接复用文件列表页 UI**，顶部面包屑显示 `archive.zip > res > drawable`。
   - 支持直接点击预览包内图片/文本、多选后点击底部「解压选中项」或「全部解压至…」、以及创建压缩包时选择格式（ZIP/7z）、压缩级别（存储/标准/极限）与加密密码。
2. **内置音乐播放器**：
   - **迷你悬浮条**：固定在列表底部上方（高 `56dp`），显示专辑小图、歌名、播放/暂停与关闭按钮。
   - **全屏播放页**：顶部返回与播放列表按钮；中部大圆角专辑封面 + 歌名/歌手；下方时间进度条；底部 5 键控制（`切换循环模式：列表循环/单曲循环/随机播放`、`上一首`、`播放/暂停`、`下一首`、`播放队列`）。
3. **内置图片浏览器**：
   - 纯黑背景沉浸式画布，支持双指捏合缩放、双击放大、左右滑动切换同目录下一张图片；单击屏幕呼出/隐藏半透明顶部栏（文件名 + 返回 + 设为壁纸/旋转/EXIF 详情）与底部栏（分享、编辑、删除）。
4. **内置文本与代码编辑器**：
   - 顶部栏：文件名 + 未保存红点提示 + 撤销/重做 + 保存图标 + 更多（切换编码 `UTF-8 / GBK`、查找与替换、显示/隐藏行号、只读/编辑模式切换）。
   - 主体区：左侧固定等宽行号槽（可选），右侧支持语法高亮与大文件分段加载。

## 3. 提供给 Google AI Studio 的分阶段执行指令

建议将本文件作为上下文附件上传给 Google AI，并分 4 步下达实现指令，以确保生成代码结构清晰且不遗漏任何 UI 细节：

1. **第一阶段（全局外壳 + 主页 + 文件列表与范围选择）**
   > “请严格对照文档第 1 节与第 2.1–2.2 节的 UI 规格，基于 Material Files 源码架构实现：`TabManager` 顶部多标签页与 `ViewPager2` 滑屏切换、快速访问侧边栏（含 Root/隐藏文件/回收站开关）、`HomeFragment` 主页看板（含设备总文件/应用数、存储轮播、分类宫格、最近文件流），以及文件列表页的「范围选择」交互、6 项指标传输弹窗、同名冲突对比弹窗与精确字节属性弹窗。”
2. **第二阶段（全协议网络 + 远程管理 + 设备快传）**
   > “请严格对照文档第 2.4 节的 UI 规格，扩展 SMB 2.0 局域网扫描、FTP/FTPS/SFTP/WebDAV/云盘配置界面，并实现 `RemoteManagerActivity` 与前台服务（支持 FTP 3721 端口与 HTTP 网页端、二维码弹窗、UTF-8/GBK 编码切换与屏幕常亮）及 ES Share 设备快传页。”
3. **第三阶段（工具箱：空间分析 + 应用管理 + 回收站 + 加密/下载）**
   > “请严格对照文档第 2.5 节的 UI 规格，实现空间分析页（环形图 + 文件夹下钻排行 + 大文件/冗余筛选）、应用管理器（三段 Tab + Split APK 备份 + 作为 ZIP 浏览）、回收站（保留原路径与剩余天数 + 还原冲突处理）、128 位加密保险箱及下载管理器。”
4. **第四阶段（内置查看器与设置中心）**
   > “请严格对照文档第 2.6 节实现压缩包文件夹式直览（ZIP/RAR/7z/OBB）、全屏/迷你音乐播放器（随机/单曲/列表循环）、图片浏览器（缩放/EXIF/设壁纸）、文本编辑器（行号/UTF-8/GBK/查找替换）以及对应的设置中心页面。”
