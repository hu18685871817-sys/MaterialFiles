# 安卓文件浏览器 · UI 与交互设计方案

> **交付边界**：本文档为设计规格说明，覆盖视觉基调、信息层级、页面布局、交互排布、图标与设置项、动效与暗色模式，**不包含应用实现与文件浏览逻辑**，可直接作为界面稿与高保真原型的输入。
> **设计语言**：shadcn/ui（骨架 + 主题 token）+ transitions.dev（动效与反馈规范），按安卓平台规范适配。
> **画布基准**：Android 360×800 dp（主基准）／412×915 dp（大屏校验）；状态栏 24 dp，底部手势区 16 dp，底部导航栏 64 dp。
> **配色版本**：**v1.1「晴彩 Bright Calm」活泼配色**（2026-11-18 修订）。在 v1.0 克制骨架基础上放宽彩色，但用 §10.1 的六条约束兜住，确保「活泼 ≠ 杂乱」。
> **配套交付物**：`素材/视觉素材板.svg`（风格参考与图标插画）、`素材/配色与素材预览.html`（亮暗可切换的可运行预览）、`AI 提示要求.md`（可直接复制给 AI 的提示词）。

## 00 · v1.1 配色变更说明

| 维度 | v1.0（克制） | v1.1（活泼） |
|---|---|---|
| 主色 | 墨蓝 `#3B5FE0` | **亮紫罗兰 `#6C5CE7`** + 渐变搭档 `#9B8BFF` |
| 类型色 | 5 组低饱和收敛色 | **8 组明快色**（锁同一饱和度带） |
| 分类宫格 | 统一浅灰底 | **每格自己的类型色 18% 浅底** |
| 存储用量条 | 单色 | **多色分段** |
| 类型图标方格 | 12% 浅底 + 1px 描边 + 1.5px 线性 | **16% 浅底 + 1.75px 线性、无实描边** |
| 空状态插画 | 单色线性 | **双色扁平 + 柔和色块** |
| 渐变 | 禁用 | **仅限 FAB / 进度条 / 成功确认等小面积强调位** |
| 骨架 | 行 + 1px 线、卡片 ≤3 张、顶部图标 ≤4 个 | **完全不变** |

**不变的**：信息架构、页面布局、交互排布、字阶间距圆角、动效 token、安卓平台适配。活泼只发生在「彩色怎么分配」，不动「信息怎么组织」。

## 01 · 设计语言路由决策

| 需求特征 | 命中语言 | 承担范围 |
|---|---|---|
| 文件列表、分类聚合、设置表单、多选管理、排序筛选 | **shadcn/ui** | 页面骨架、语义化颜色 token、1px 描边分层、卡片/列表/表单/按钮样式、亮暗双主题 |
| 排序面板、菜单、Toast、勾选、骨架屏、页面切换、搜索清空、开关 | **transitions.dev** | 全部微过渡与状态反馈，动效 token 化 |
| 苹果毛玻璃 / 灵动岛 / spring 手感 | beUI | ❌ 不采用，与安卓 Material 语汇冲突 |
| 炫酷吸睛动画组件 | Rare UI | ❌ 不采用，与工具界面的信息密度矛盾（活泼靠配色，不靠特效） |
| AI 原生界面 | Beautiful UI | ❌ 不采用，本产品无 AI 场景 |

**组合原则**：主题色以 shadcn 语义 token 为**单一事实源**，其余只引用不另定义；动效参数统一到 transitions.dev 的 token 体系；冲突时「微过渡优先 transitions、面板手感优先克制的 spring 补充」。
**v1.1 对 shadcn 的有分寸打破**：shadcn 铁律是「彩色只出现在 primary/destructive」，本次按用户要求放宽为「**多色 accents 只做类型识别**」，但 primary 仍唯一、正文仍中性，见 §10.1 六条约束。

## 02 · 风格方向（Style Direction）

**情绪：明快、轻盈、可靠。** 比 v1.0 多一分朝气，但仍是一个「找得到、拿得走」的工具——活泼来自**有节奏的彩色分配**，不来自装饰和特效。

- **配色策略**：中性偏冷的极浅底（`#F7F8FE`）上，主色只用一个**亮紫罗兰 `#6C5CE7`**，负责「当前位置 / 选中 / 主操作」；**8 组明快类型色**按文件类别分配，出现在分类宫格、类型图标方格、存储分段条、空状态插画里。所有类型色锁定同一饱和度带（S 65~78% / L 58~68%），不出现荧光色与深色并存——**统一饱和度是「活泼但不刺眼」的关键**。文件名、元数据、正文一律保持中性色，彩色绝不进入文字。
- **字体气质**：系统无衬线；**数字统一 tabular-nums**（文件大小、日期、数量必须列对齐，这是"精致"最容易被忽略的一处）。层级靠 400 / 500 / 600 三档字重 + 明度拉开，不靠把字号猛缩来压次级信息。
- **布局哲学**：单列、左对齐、呼吸留白。信息密度用「行」组织，不用卡片堆砌——**列表页坚决用行 + 1px 分隔线，卡片只留给首页概览、详情属性、空状态**。这是解决「界面杂乱分散」的关键决策，v1.1 完全保留。
- **组件风格**：圆角全部从单一 `--radius` 派生；**描边优先于阴影**，阴影只给浮层（下拉、菜单、bottom sheet、FAB）；顶部操作用图标按钮，主操作用 FAB；导航用底部 4 tab（安卓语汇），不用侧边抽屉。渐变只用在 FAB、存储分段条、进度条、成功确认这类小面积强调位（primary → primary-2），**禁止大面积渐变背景与多色渐变**。
- **三个独特细节**：
  1. **面包屑路径可横滑**，每一级都是可点的「位置锚点」，长按复制完整路径；
  2. **统一的文件图标方格**：类型色 · **16% 浅底 + 1.75px 同色线性符号**（无实描边，更透气）；只有图片/视频缩略图允许破格铺满圆角方格；
  3. **列表行右侧恒留一个 ≥44×44 的「更多」热区**，长按与点按结果完全一致，把学习成本压到零。

## 03 · 信息架构与页面地图

**四个一级 Tab + 三个二级页**，正好覆盖需求点名的全部页面；二级页从任意入口进入，不占底部导航。

| 页面 | 层级 | 一句话职责 | 核心模块 | 主要入口 |
|---|---|---|---|---|
| **首页** | Tab 1 | 一屏看清「空间还剩多少、最常用什么」 | 存储用量、快捷分类宫格、最近文件预览、常用位置 | 底部导航 |
| **最近文件** | Tab 2 | 按时间回溯最近改动 | 时间分组、类型筛选 chips、清理建议卡 | 底部导航 |
| **分类浏览** | Tab 3 | 按类型／来源聚合，脱离目录层级找文件 | 类型宫格、存储位置、收藏夹、回收站、大文件 | 底部导航 |
| **文件列表** | 二级 | 浏览单一目录并完成排序／筛选／多选管理 | 面包屑、排序筛选条、列表/网格、多选操作条、FAB | 首页 / 分类 / 最近 / 存储位置 |
| **搜索** | 二级（覆盖层） | 全局跨目录检索 | 搜索框、历史与建议、条件筛选、结果分组 | 任意页顶部搜索图标 |
| **文件详情** | 二级（面板或页） | 单个文件的完整信息与可用操作 | 大预览、属性表、路径、操作区 | 列表行「更多」/ 长按 / 点击 |
| **设置** | Tab 4 | 偏好与行为配置 | 六组设置项（见 §09） | 底部导航（也可收为「更多」+ 首页齿轮） |

**跳转主干**：`首页/分类/最近 → 文件列表 → 文件详情`；`任意页 → 搜索 → 文件列表/详情`；`分类 → 存储位置 → 文件列表`。返回键与顶部返回箭头行为一致，面包屑可跨级回跳。

## 04 · 全局框架

### 4.1 底部导航（固定，4 tab）

| 位 | 图标 | 文字 | 选中态 |
|---|---|---|---|
| 1 | `home` | 首页 | 图标切换为填充变体 + primary 色，文字转 600；顶部 2dp primary 指示条（不使用药丸背景块） |
| 2 | `clock` | 最近 | 同上 |
| 3 | `grid-2x2` | 分类 | 同上 |
| 4 | `settings` | 设置 | 同上 |

- 高度 64 dp（含底部手势区 16 dp），背景 `--card` + 顶部 1px `--border`；**不用阴影、不用模糊**。
- 每项触控热区 ≥ 48×48；图标 24、文字 11sp/500。
- 双击当前 tab 回到该页顶部并收起浮层；tab 切换用 250ms 的 8px 位移 + 3px 模糊交叉溶解。
- 进入多选模式时底部导航**下移隐藏**，让位给操作条。

### 4.2 顶部操作（AppBar，按页面形态切换）

| 形态 | 左侧 | 中间 | 右侧图标组（顺序固定） |
|---|---|---|---|
| 一级 Tab 页 | 无（标题左对齐） | 页面标题 20/600（首页为 26/600 大标题 + 存储概览） | `search` · `list-filter` · `more-vertical` |
| 文件列表 | `arrow-left` | **面包屑路径**（横滑，末级 600 + primary） | `search` · `list-filter`(排序筛选) · `list/grid`(视图切换) · `more-vertical` |
| 搜索 | `arrow-left` | 搜索输入框（自动聚焦，full 圆角） | `x`(清空) / `mic` |
| 文件详情 | `x`（若用底部面板） | 标题「详情」 | `more-vertical` |
| **多选模式（临时替换）** | `x` 退出 | **已选 N 项**（数字变化时 150ms 数字切换） | `check-all` 全选 |

- AppBar 高 56 dp，背景 `--background`，滚动后加 1px 底边线（不加大阴影）；所有图标按钮热区 44×44，图标 20~22。
- 「更多」用锚定下拉菜单的 overflow，不把操作摊平到顶部——**顶部保持 3~4 个图标以内**，是防杂乱的硬约束。

### 4.3 安全区与栅格

左右留白 **16 dp**（≥600dp 宽用 20 dp）；内容底部恒预留 ≥ 64+16+24 dp，保证最后一行不被 tab bar 与手势条压住；分组间距 24 dp，组内卡片间距 12 dp。

## 05 · 逐页设计

### 5.1 首页
- **区块（自上而下）**：① 大标题「文件」+ 副标题（如「内部存储 · 已用 68.4 GB / 128 GB」）；② **存储用量卡**：一条 8dp 高的**多色分段**进度条（按图片/视频/文档/其他分段，直接取对应类型色，段间留 2dp 白缝）+ 右侧数字（tabular）；③ **快捷分类宫格 2×4**（图片 / 视频 / 音频 / 文档 / 下载 / 压缩包 / 安装包 / 收藏），**每格用自己的类型色 18% 浅底**（v1.1 最直观的活泼点）+ 40dp 类型图标方格 + 名称 + 数量；④ **最近文件**（3~5 条，紧凑单行列表 + 「查看全部 →」）；⑤ **常用位置**（内部存储 / SD 卡 / 云盘，带容量条）。
- 卡片：`rounded-lg` + 1px border + `--card`，内边距 16；**全页最多 3 张卡片**，其余用分组标题 + 行。
- 状态：无权限时存储卡降级为「授权后可查看用量」+ [去授权]；首次进入骨架屏。

### 5.2 最近文件
- **时间分组**：今天 / 昨天 / 本周 / 更早（sticky 分组头，12sp/500、`--muted-foreground`、底 1px border）。
- 顶部一条**类型筛选 chips 横滑**（全部 / 图片 / 视频 / 文档 / 压缩包…）；「全部」选中用 primary 12% 底，**具体类型 chip 选中可用该类型色 14% 浅底 + 同色文字**（v1.1 新增），药丸指示器 250ms 滑动。
- 行结构同文件列表「双行行」；右侧显示相对时间（「今天 14:32」）。
- 顶部可选**清理建议卡**：「发现 1.2 GB 可清理的大文件」+ [查看] / [忽略]，可关闭且记住忽略；卡片左侧可用 warning 色小图标做点缀。
- 空态：见 §07；下拉刷新（仅此页与云盘）。

### 5.3 分类浏览
- **类型宫格**：图片 / 视频 / 音频 / 文档 / 压缩包 / 安装包 / APK / 收藏，网格 2 列、间距 12；**每格底色 = 该类型色 18% 浅底**（v1.1），格内显示缩略图拼贴（前 3 张，圆角 8）或类型图标 + 名称 + 数量 + 占用大小。颜色是分类识别，不额外加描边和阴影。
- **存储位置区**：内部存储、SD 卡、云盘账户（每行：图标 + 名称 + 已用/总量细进度条 + `chevron-right`），进度条用 primary 渐变。
- **工具区**：大文件（>100MB）、重复文件、回收站、下载目录、隐藏文件夹，用**行**而非卡片。
- 分区之间只用 24dp 留白 + 1px 分隔线，不加卡片背景。

### 5.4 文件列表（核心页）
- **顶部三层**：AppBar（面包屑）→ **排序筛选条**（横向 chips：当前排序「按修改时间 ↓」· 筛选「类型」· 视图切换；有激活筛选时显示「已筛选 · 清除 ×」）→ 列表。
- **行结构（双行，行高 64 dp）**：
  - 左：40×40 **类型图标方格**（v1.1：16% 类型色浅底 + 1.75px 同色线性符号，无实描边）或 40×40 圆角缩略图；**文件夹永远用图标方格，不用缩略图**
  - 中：第一行文件名 16/600（**1 行省略，保留扩展名**），第二行 `大小 · 修改时间 · 子项数`（12sp/`--muted-foreground`）
  - 右：① 收藏星标（仅已收藏显示，节省空间）② `more-vertical` 44×44 热区
  - 行间 1px `--border` 分隔线，**从图标右缘起缩进 56dp**（不贯穿整行，视觉更齐）
- **网格视图**：2~3 列（按宽度自适应），单元 = 1:1 缩略图（圆角 8）+ 2 行文件名 + 1 行大小；选中态在缩略图右上叠加勾选圈。
- **排序按文件夹优先、文件夹内按当前规则**；`.` 开头隐藏文件默认不显示（设置可开），显示时用 60% 不透明度 + `eye-off` 小角标。
- **FAB**：右下 56×56 圆形，**primary → primary-2 的 135° 双色渐变**（v1.1 允许的唯一常驻渐变位），图标 `plus`；展开为「新建文件夹 / 上传 / 扫描」三行菜单（350ms morph）。滚动向下时 FAB 轻微收缩隐藏，向上即现。
- 状态齐全：加载骨架屏 / 空目录 / 无权限 / 加载失败 / 多选。

### 5.5 搜索
- 覆盖层进入（250ms 上滑 + 模糊交叉溶解），输入框自动聚焦、键盘弹起。
- **未输入时**：搜索历史（可单条删除、可「清空历史」）+ 热门建议 + 快捷筛选（类型 / 时间 / 大小 / 范围：全部 or 当前目录）。
- **输入中**：即时建议（文件名高亮命中片段，primary 色 600）；**结果按类型分组**并标注「共 N 项 · 用时 xx ms」；分组头左侧可加 8dp 类型色圆点。
- **条件筛选**：底部面板，类型多选 chips、时间范围、大小区间、位置范围；底部「重置 / 查看 N 个结果」。
- 清空输入用 400ms 溶解；无结果与错误态见 §07。

### 5.6 文件详情
- 以 **bottom sheet（展开至 90% 高度）** 或整页呈现，顶部为 大预览区（图片/视频铺满，其余用 64×64 类型方格居中；不可用则显示格式大字如「PDF」）。
- **属性表**（左标签 12sp muted / 右值 14sp，行高 44，1px 分隔）：名称、类型、大小、所在路径（可点跳列表）、修改时间、创建时间、权限、MD5（折叠展开）。**数值列右对齐 + tabular-nums**。
- **操作区**：主操作 `[打开方式]`（primary 渐变实心按钮），次操作行 `分享 · 复制/移动 · 重命名 · 收藏 · 压缩`，危险区 `[移至回收站]`（destructive 文字 + 细描边，二次确认）。
- 属性行长按可复制值并 Toast 反馈。

### 5.7 设置
见 §09 分组；采用 **分组标题 + 行** 结构，不用卡片包裹每组；行高 56，右控件（switch / 值 + chevron / 单选）；分组间 24dp + 1px 分隔。顶部保留品牌信息小卡（图标 + 名称 + 版本）作为唯一视觉锚点；**分组标题左侧可加 8dp 类型色圆点**做轻量节奏（每分组一色，不重复）。

## 06 · 核心交互规范

### 6.1 排序与筛选
- **排序维度**：名称 / 修改时间 / 大小 / 类型；各可升↔降；默认「修改时间 ↓」；文件夹恒优先。
- **筛选维度**：类型（多选）、时间范围、大小区间、仅文件夹、显示隐藏文件、位置范围（全局/当前目录）。
- **载体**：底部筛选面板（bottom sheet，安卓语汇，400ms 开 / 350ms 关），排序用单选列表 + `check` 图标，筛选用 chips + switch；底部固定「重置 / 显示 N 个结果」。不用下拉菜单承载复杂筛选。
- 排序条上直接展示**当前规则文字**，一键可改升降序；有激活条件时显示「清除 ×」。
- 每个目录的排序与视图偏好默认记住（设置可关），切换视图用 250ms icon swap。

### 6.2 多选管理
- **进入**：长按任意行 / 顶栏「选择」/ 直接点勾选框；行左侧滑入 checkbox（150ms 填充 + 350ms 描边画勾）。
- **选择态 AppBar**：`x` 退出 · 「已选 N 项」· 「全选」；**底部导航隐藏**。
- **选中行样式**：primary 8% 底 + 左侧 3dp primary 竖条 + 勾选框填充；克制、不加阴影不加放大。
- **底部操作条**（替换 FAB，350ms 浮起）：`分享 · 复制 · 移动 · 压缩 · 更多`；`重命名` 仅单选可用（否则置灰并提示）；`删除` 用 destructive 且必须二次确认。
- **支持范围连选**（长按起止两点）+ 全选/反选；退出路径：X / 返回键 / 取消全部选中。

### 6.3 快捷操作
| 手势 / 控件 | 结果 |
|---|---|
| 短按行 | 打开文件或进入文件夹 |
| 长按行 | 进入多选（安卓惯例） |
| 点行右 `more-vertical` | 锚定下拉菜单：打开方式 / 重命名 / 复制·移动 / 分享 / 收藏 / 压缩 / 详情 / 删除 |

### 7.2 反馈层次
| 级别 | 载体 | 用于 | 规范 |
|---|---|---|---|
| 轻 | Toast | 已复制、已收藏、重命名完成、路径已复制 | 慢进 350ms / 快出 250ms，≤ 2 行，底部浮层，不遮挡操作条；成功态可用 success 色小图标 |

### 10.1 色彩 token（设计稿取 hex；工程落地映射为同名语义变量）

**类型色 8 组**见 §08 表格（亮/暗双值齐备）。

#### 活泼配色的六条约束（防「活泼 → 杂乱」的硬规则）

1. **彩色只进容器，不进文字**：文件名、元数据、正文、设置标签一律中性色；彩色只出现在图标方格、分类格、进度分段、插画、选中态、主按钮。
2. **主色仍唯一**：`--primary` 只有紫罗兰一个；8 组类型色只做「类型识别」，**绝不用于按钮 / 选中 / 导航 / 主操作**。
3. **饱和度锁带**：所有类型色锁定 S 65~78% / L 58~68%，不出现荧光色与深色并存；暗色统一「降饱和 + 提亮」。
4. **一屏彩色 ≤ 5 组**：首页分类宫格 8 格为例外，但用**统一方格形状 + 统一 18% 浅底明度**收敛，不靠描边和阴影。
5. **骨架不变**：行 + 1px 缩进分隔线、卡片每屏 ≤3 张、顶部图标 ≤4 个、圆角单源派生、阴影只给浮层——全部保留。
6. **渐变克制**：只允许 FAB、存储/容量进度条、成功确认等**小面积强调位**用 `primary → primary-2` 的 135° 双色渐变；**禁止大面积渐变背景、禁止三色及以上渐变、禁止类型色渐变**。

**铁律**：组件里禁止写死颜色，一律走语义 token；彩色只出现在上表与 §08 的 8 组类型色；页面底与卡片只差一档明度。设置里提供「彩色强度」可整体回退。

## 11 · 暗色模式

- 三态可选（跟随系统 / 浅 / 深），`.dark` 覆盖同名 token，**组件零改动**；切换即时生效，无闪烁（先切变量再重绘）。
- 关键差异：`background` 用 `#12121F` 深紫黑而非纯黑（避免 OLED 光晕与"死黑"，同时呼应主色）；`primary` 提亮到 `#A79BFF` 保证 ≥ 4.5:1；`border` 一律**透明白 10%**（不用实色灰线，避免暗色下白线刺眼）；`input` 透明白 15%。
- **8 组类型色在暗色下统一「降饱和 + 提亮」**（见 §08 暗色列），容器底仍保持 16% 透明度；分类宫格浅底由 18% 降为 **14%**，避免暗色下发灰发脏；缩略图叠 4% 暗角。
- 阴影在暗色下减弱约 40%，优先改由 border + 极轻描边承担层次；注意 `mix-blend-mode: multiply` 类效果在暗色需翻为 `screen`。
- FAB / 进度条渐变在暗色下改用 `primary(暗) → primary-2(暗)`，明度差不超过 12%。
- 状态栏图标、底部导航、Toast 背景随主题反相；骨架屏 shimmer 由浅灰改为 `rgba(255,255,255,.06)`。
- 对比度：正文 ≥ 4.5:1，次级文字 ≥ 3:1（≥18sp 可放宽），图标与边框 ≥ 3:1。

| 缓动 | `--ease-smooth-out` / `--ease-in-out` / `--ease-out` / `--ease-bounce` | `cubic-bezier(.22,1,.36,1)` / `ease-in-out` / `ease-out` / `cubic-bezier(.34,1.36,.64,1)` |
| 距离 | micro 4 / small 6 / **base 8** / medium 12 / large 30 px | 位移不超过档位 |
| 缩放 | modal .96 / dropdown .97 / tooltip .98 | 起始缩放，永远朝 1 过渡 |
| 模糊 | 2px 常规 / 3px 大位移 / 8px 成功确认 | **模糊交叉溶解**代替生硬淡入 |

**铁律：进慢出快**（开 250 / 关 150）；常规反馈 ≤ 250ms；仅骨架屏揭示与成功确认允许 400 / 500ms；逐属性 `transition`，不写 `all`；**必须保留 `@media (prefers-reduced-motion: reduce)` 降级到 0.01ms**。

## 13 · 平台适配与无障碍

- **安卓规范**：返回键 = 顶栏返回（优先退出多选 → 收浮层 → 回上一级）；状态栏 24dp 且图标随主题反相；手势区 16dp；bottom sheet / FAB / Snackbar 遵循 Material 语汇；不使用 iOS 的 44pt 状态栏与 Home 指示条。
- **触控**：所有可点区域 ≥ 44×44dp（列表行整行可点，图标按钮靠 padding 扩热区）；滑动操作带阈值与回弹，避免误触删除。
- **无障碍**：正文对比度 ≥ 4.5:1；所有图标按钮提供 contentDescription；字号用 sp 并校验 200% 字体缩放不破版（文件名省略、属性表换行）；**不只用颜色传达状态**——类型除颜色外还有不同的线性符号，选中同时有勾选框与竖条，错误同时有图标与文字。
- **性能**：动效只作用在目标元素（如 badge 动画 dot 而非 trigger）；重播动画前 `void el.offsetWidth` 强制 reflow；关闭态类及时清理，避免下次打开跳变。

## 15 · 落地建议

**界面稿清单（建议 7 张 + 3 张附录）**：首页 / 最近 / 分类 / 文件列表（列表态 + 多选态）/ 搜索（未输入 + 结果 + 无结果）/ 文件详情 / 设置；附录：空状态合集、组件清单（AppBar、行、chips、图标方格、FAB、Toast、筛选面板）、token 色板。

**原型规格**：单文件 HTML，内联 CSS/JS，各页用同文件 section + 底部导航切换；画布 360×800（可切 412×915 校验）；图标内联 SVG、图片用 CSS 渐变或 SVG 占位，不依赖 CDN；`:root` 写全套设计 token、`.dark` 覆盖同名变量；每屏真实中文文案（如「周三 · 项目周报.pdf · 2.4 MB」），导航与主要按钮可点。可直接以 `素材/配色与素材预览.html` 的 `:root` 块作为 token 起点。

**组件优先级**：P0 列表行 / AppBar / 底部导航 / 筛选面板 / 空状态；P1 面包屑 / 多选操作条 / 详情面板 / Toast；P2 设置分组 / 全量动效 / 暗色模式。

**可调点**：① 底部第 4 tab 可改为「更多」并把设置收为首页右上齿轮的二级页；② 强调色可换「晴空蓝 `#3B9BFF`」或「蜜柚橙 `#FF7A59`」，只需替换 `--primary` / `--primary-2` 一对变量；③ 左滑手势是否开放删除（当前方案保守不放）；④ 彩色强度默认「标准」，可改「柔和」降低饱和与浅底占比。
